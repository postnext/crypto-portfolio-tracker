# Crypto Portfolio Tracker 🪙

Простий Python-скрипт для відстеження вартості вашого крипто-портфеля.

## 📌 Як використовувати?
1. Встановіть Python 3+
2. Встановіть необхідні бібліотеки:
   ```
   pip install requests
   ```
3. Додайте свої активи в `portfolio.json`
4. Запустіть скрипт:
   ```
   python crypto_portfolio.py
   ```
